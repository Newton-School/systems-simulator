# Lecture Scripts

Use a predict–observe–explain sequence:

1. State the givens and ask for a prediction; completion is scored, not accuracy.
2. Show the smallest useful wrong design and ask what the result means.
3. Change one visible decision at a time.
4. End on the smallest accepted design and connect it to the napkin model.

For each step record topology, dial values, talking point, expected result, and
misconception addressed. Keep projector sequences to two to four steps.
