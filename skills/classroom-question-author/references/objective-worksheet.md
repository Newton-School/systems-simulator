# Objective Worksheet

| Field                             | Author entry                                      |
| --------------------------------- | ------------------------------------------------- |
| Source question                   | Verbatim prompt or section                        |
| Dominant lesson                   | One sentence                                      |
| Objectives                        | “The student can…” statements                     |
| Givens                            | Every fact supplied by the problem                |
| Student decisions                 | Structure, copies, or registered choices          |
| Decision → objective              | One objective ID per decision                     |
| Napkin model                      | Formula or qualitative reasoning                  |
| Smallest accepted solution family | Components and permitted variants                 |
| Plausible wrong designs           | Two to four                                       |
| Classroom outcome                 | Direct, structural, Architect handoff, or blocked |

Reject a control with no objective. Reject a numeric given absent from the source
unless the author explicitly adds it to the problem statement.
